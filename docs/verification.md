| 问题 | 结果 | 归一化前目标质量 |
| --- | --- | ---: |
| refund / Noul | P(Yes) = 0.9999998170 | 99.99998253% |
| department / Choice | billing | 99.99989848% |
| urgency / Score | 0.6511138433 | 99.99624306% |
