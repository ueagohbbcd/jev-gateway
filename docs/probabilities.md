# 概率、温度和诊断

对单次调用，在首输出位置把返回的 logprob 转成原始概率。只接受配置中精确的标签字符串，不折叠大小写、不合并前导空格、不读取后续 token，也不把采样文字当作最终答案。

## 读取与质量界

令 O 为已观察到的去重 token 集合，A 为目标标签集合。采样 token 若有有效概率，也加入 O；它不一定在 top-k 中。无效数值及 -9999 哨兵不作为概率使用。

目标质量下界 `L = sum(exp(lp[t]) for t in A ∩ O)`。剩余概率 `R = max(0, 1 - sum(exp(lp[t]) for t in O))`。缺失目标数为 m；若有效 top-k 列表末位概率为 c，则：

```text
U = L + min(R, m × c)
```

top-k 截止值不可靠时仅用剩余质量作保守上界。目标全部出现时 U=L。界限基于供应商返回的概率精度和 top-k 排名约定，浮点舍入可能产生极小误差。

这衡量的是精确目标标签占词表概率的多少，不是正确率。模型可以极自信地选错；原始质量 99.9% 也不能保证所有候选进入 top-k。

## 温度缩放

已观察目标使用 logprob，缺失目标按负无穷（概率 0）处理，然后：

```text
p_i(T) = exp((lp_i - max(lp)) / T) / sum_j exp((lp_j - max(lp)) / T)
```

T=1 是原始目标内归一化；T>1 变平，0<T<1 变尖。正温度不改变单次候选排序，但改变 Noul 数值、Score 期望和集中度 confidence。二分类 T=3 时，99%、99.9%、99.99% 分别变成约 82.23%、90.91%、95.56%。多分类必须使用完整向量，不能只变换最大概率。

温度在每次请求归一化时应用，双循环在它之后聚合，不再二次缩放。原始质量上下界始终在温度之前计算。配置中的温度不是上游请求的采样 temperature。

缺失目标的 0 经任何正温度仍为 0；温度不能恢复隐藏信息。升温会放大真实尾部，所以即便 T=1 时补零误差很小，也不能保证升温后误差仍小。启用温度且存在缺失时会单独告警。

旧实验 310 道完整分布题、20 个案例的分组五折分析中，T 约 2.8 将 NLL 从 0.5117 降到 0.3023，ECE 从 10.02% 降到 2.79%。这只是旧提示词、旧字母协议对模型共识 reference 的开发数据结果。本仓库的默认模板及直接 Yes/No 未用这份参数独立验证，因此默认 T=1。

## 双循环

每对候选进行两个方向的调用。把各场结果映射回语义键，对两个方向取概率均值。每个候选的胜分为对所有对手的期望获胜概率之和，再除以全体候选的胜分总和，得到最终分布。Score 对这个分布取等级期望。

该算法不对零概率取 log-odds，不需要暗中加 epsilon。它是一种明确的锦标赛近似，不是恢复全选项的真实联合概率。即使某候选稳定战胜所有对手，归一化胜分也未必接近 1；不要把单次模式的置信阈值直接照搬过来。Noul 不使用双循环。

与旧实验室的双循环有一处有意区别：旧版先平均两种顺序的 log-odds，新版平均概率。这样缺失补零时不会出现无穷值或需要任意平滑常数；两种算法不保证相同答案。旧实验未实际跑过双循环，不能把单次测试成绩当成这一聚合策略的验证。

## 告警和数据出口

标准 HTTP 响应只给兼容字段。结构化 stderr 日志提供请求 ID、配置 ID、每次调用的概率质量、缺失数量和告警。CLI 的 `evaluate --diagnostics PATH` 额外保存完整证据，包括实际提示词、映射、原始标签 logprobs、温度前后分布和 top token；默认不落盘。

| 条件 | 含义 |
| --- | --- |
| 目标未全部出现 | 完整返回分布中包含补零近似 |
| U 小于质量门槛 | 可以确认目标质量过低 |
| L 小于门槛但 U 不低于门槛 | 不能确定是否过低 |
| 非目标 token 居首或并列第一 | 输出协议偏离，目标内分布仍返回并明确告警 |
| 缺目标且 T 不为 1 | 升温／降温在不完整数据上计算 |

归一化本身不告警。告警不修改答案、不触发额外付费重试；目标全缺失则失败，因为没有可归一化的观测证据。

单次 Choice/Score 的标准 probabilities 足以再做温度变换（已有温度 T 改到目标 T'，相当于对当前分布取 T/T' 次幂再归一化）。单次 Noul 的标量可还原二分类条件分布。它们均无法恢复归一化前质量或缺失标签；双循环的最终分布也无法恢复各场证据，不能等价重做聚合前变换。需要这些能力时保存完整诊断。
